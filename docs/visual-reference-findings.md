# 运动表现分参考应用：视觉借鉴记录

参考页面：<https://itra-perf-fjxerg9i.manus.space/>  
观察日期：2026-08-19（GMT+8）

## 观察结果

参考应用以浅雾绿色背景、低饱和山景主视觉和大面积留白建立轻松、可信的第一印象。主操作聚焦为单一深绿上传按钮；首屏清晰交代“本地浏览器处理、不会上传”的数据边界。分析内容被收拢在一张宽度克制的白色工作卡中，卡内采用标题、短说明、操作区、关键指标和解释性脚注的顺序，用户不必在大量平铺面板之间跳转。

数值呈现较为克制：大字号表现分与“里程当量 / 分段策略 / 用时累计”并列，形成一次扫描即可理解的结果区。预设和自行设定以分段标签切换；说明、免责声明与版权信息使用较弱层级，但仍放在结果附近以避免结论脱离适用边界。页面在 1280px 宽视口下采用单列内容轨道，主标题为深绿 48px，主要分区标题为 24px，次级标题为 16–18px。

## TrailCraft 的借鉴边界

TrailCraft 不复制该应用的内容、品牌、山景构图或页面代码。其可借鉴之处是：用短说明建立数据边界；一项高价值主操作；任务级而不是控件级的信息分组；减少同时可见的选项；在结论旁保留可信度、来源与限制。

TrailCraft 将保留既定的“地图舞台 + 工具脊柱 + 数据地形带”布局和山径橙品牌色。视觉上，路线工作台可借鉴参考应用的**留白、低干扰卡片、指标并列和单一行动焦点**；但地图、轨迹、CP 和高程仍需占据更大的空间，不会被改造成单列指标页。
