# 三维巡游渲染缺陷记录

日期：2026-08-20

用户报告：二维轨迹已能正常显示，但三维巡游不显示。

已在已发布版本进入“三维巡游”。画布区域从二维地图切换为黑色工作区，并持续显示“正在加载三维引擎…”，说明问题至少覆盖 Cesium 延迟运行时或 `createViewer` 完成前的链路，尚未进入可用的三维场景状态。当前会话没有导入轨迹，因此下一步先检查运行时脚本、Assets、Workers 与控制台；随后将用真实 GPX 回归相机和路线实体。

等待后，浏览器自动化未返回可读页面元素；控制台未输出应用错误。这种表现与 WebGL/大资源加载导致的无头浏览器会话失效相符，但不足以解释真实设备的黑屏，因此将直接检查生产资源端点和加载器行为，并加入不依赖外部影像的场景首帧与诊断回退。

生产包检查发现根因之一：先前静态复制配置将 Cesium 的 `Workers`、`Assets` 和 `Widgets` 内容扁平化到 `/cesium`，而运行时实际请求 `/cesium/Workers/*`、`/cesium/Assets/*` 与 `/cesium/Widgets/*`，已发布域名对应端点返回 404。配置已修正，且新生产包中四类关键文件都位于标准路径。开发预览在切换三维后仍短暂显示“正在加载三维引擎…”，因此还需读取真实加载器结果和 WebGL 创建状态。

无头浏览器在三维加载后控制台无应用错误，但页面 DOM 已不再包含 FlyView、Cesium 脚本或画布；这与其 WebGL 会话重置一致，不能作为真实设备上 Viewer 成功与否的证据。生产资源路径错误已形成确定性修复，后续将为运行时增加有限超时和可见的降级场景，以确保真实设备不会永久卡在加载遮罩。

修复资源层级并重启开发服务后，干净无头浏览器会话成功完成 Cesium 初始化：黑色加载遮罩已消失，画布展示中国及周边的三维地球与 Esri 影像；状态徽标显示“地形：平面(三维地形服务不可达) · 影像：Esri”。这证明外部地形在当前环境被正确降级，而不再阻塞 Cesium 场景首帧。下一步需导入真实 GPX，回归路线实体与相机巡游。

在已初始化的三维场景中，路线导入输入可正常定位，说明 FlyView 与导入工作流可并存。准备直接上传真实 GPX，观察实体同步、自动飞行与俯瞰镜头。

用户最新截图显示巡游模式中的 HUD、播放进度、底图切换与“跟随 / 俯瞰 / 自由”控制均已就绪，当前为“自由”镜头；但地图画布上没有路线折线、起点或终点标识。故障范围已收敛为三维轨迹实体的渲染与进入巡游时的镜头聚焦，而非 Cesium 引擎初始化。

新建的无头浏览器会话再次在 Cesium 初始化等待后失去可读页面元素，无法稳定承载实体导入回归。真实设备截图已足以证明场景工作、实体不可见；后续将通过增强实体材质与渲染层次、明确进入巡游时的路线聚焦，并在代码中加入可读诊断信息来修复与验证。

双层路线与自动聚焦改造后，新的干净会话可稳定进入 Cesium 场景并展示地球与 Esri 影像；状态仍明确提示三维地形服务不可达而采用平面降级。当前会话尚未导入轨迹，下一步仅验证实体导入与镜头对路线范围的聚焦。

已在三维场景会话中确认真实路线文件输入可定位并可上传；场景画布、降级状态提示与导入面板均保持可用，准备提交仓库中的真实 GPX 样例。

用户要求的导航调整已在开发预览首屏生效：顶部仅保留“路线工作台”和“工具库”，第04步仍为“输出与巡游”。该会话在随后等待 Cesium 时再次失去无头页面元素，故将以可视静态检查、生产构建和真实设备复测完成最终验收；不能把无头会话的重置误判成新功能错误。

用户提供的 Claude Code 回溯说明了一个**二维 MapLibre** 历史问题：Vite 预打包破坏其 Worker，导致 GeoJSON 线不绘制。当前项目已在 `vite.config.ts` 中保留 `optimizeDeps.exclude: ['maplibre-gl']`，且二维轨迹已由用户确认恢复，因此该线索不构成巡游实体缺失的根因，但强化了“数据层正确不代表实际绘制”的诊断原则。

本轮三维修复将路线渲染改为双层：保留原有贴地发光线，同时增加一条高于地形的普通高对比安全线，并配合深度失败材质；这为地形贴合或材质路径异常提供独立的可见性保障。进入巡游、切换活动路线以及用户点击“聚焦路线”均会以安全线的范围重新框选相机，从而避免“自由”镜头遗留在全局视角。`pnpm check` 与生产构建均已通过，且生产包包含 Cesium 脚本、Workers、Assets 和 Widgets 的标准目录。

用户随后提供的真实巡游截图显示两项确定性缺陷：其一，选择“道路底图”会通过 `terrainProviderForStyle` 将 Cesium 切换到平面椭球，造成“三维巡游”没有山体起伏；其二，贴地发光线与高于地形的安全线同时可见，形成明显重影。已改为道路与卫星影像均保留同一真实地形提供方，并设置适度垂直夸张；实体渲染按提供方能力二选一（真实地形为贴地线，椭球降级为单条安全线）。当降级发生时，画布将展示“平面地形预览”而非伪装为有地形的巡游。第04步进入时也会重置到俯瞰镜头。

本轮无头浏览器可验证控件文案与深色主题，但在触发 Cesium 点击后仍会失去可读页面元素，因此最终路线实体与实际山体效果需要真实 Chrome/Edge 使用同一 GPX 再次确认。生产构建与类型检查通过。
