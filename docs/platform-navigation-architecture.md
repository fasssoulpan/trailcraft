# TrailCraft 平台导航与工具架构

**参考对象：** Roadman Cycling 工具页（仅借鉴信息架构，不复制品牌、文案、代码或视觉资产）。

## 参考观察

Roadman 将内容、主题、工具、社区与服务放在稳定顶层导航中，并以“YOUR TOOLKIT”作为工具集合的单一入口。工具卡以问题、适用输入和下一步行动组织，用户不必理解内部产品结构即可进入需要的计算器。该模式适合 TrailCraft 后续增加独立的小工具。[1]

## TrailCraft 平台架构

| 层级 | 首发内容 | 后续扩展方式 |
| --- | --- | --- |
| 顶部导航 | 路线工作台、工具库、三维巡游、帮助 | 固定平台壳层，不因新增工具改变位置 |
| 工具库 | 路线工作台（已实现）、赛前简报、补给与配速、表现工具 | 已实现工具可进入；未实现工具必须标记“即将推出”，不伪装成功能完成 |
| 工作区任务轨道 | 导入与校验、路线编辑、赛前分析、输出与巡游 | 每个阶段只展示当前高频操作，高级选项进入抽屉 |
| 三维巡游 | 地形、镜头、关键帧、速度与导出 | 作为一等工具入口，与二维编辑共享当前项目和活动路线 |

## 人体工学原则

平台导航解决“我想用哪类工具”，任务轨道解决“当前路线下一步该做什么”，右侧洞察区解决“这条路线目前处于什么状态”。三层信息不混用：导航不承载细节参数，地图不被低频表单遮挡，导出和高级设置不进入导入首屏。

## 首发候选工具文案

| 工具 | 状态 | 用户行动 |
| --- | --- | --- |
| 路线工作台 | 可用 | 导入、校验、编辑并输出路线项目 |
| 三维巡游 | 开发中 | 以当前活动路线生成地形巡游和镜头路径 |
| 赛前简报 | 即将推出 | 汇总距离、爬升、CP、风险和预计时间 |
| 补给与配速 | 即将推出 | 按关门、地形与目标时间生成策略 |
| 表现工具 | 即将推出 | 对实跑轨迹进行表现与恢复分析 |

## 当前实现验证

新版导航已在内部预览中验证：从“路线工作台”可以进入“工具库”，工具库提供山脊主视觉、路线工作台与三维巡游的可用入口，并将赛前简报、补给与配速、表现工具明确标注为“即将推出”。这避免未来工具尚未实现时被误导为可用功能。
