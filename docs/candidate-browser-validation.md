# TrailCraft 公众候选浏览器验证记录

日期：2026-08-20

## 已确认

桌面浏览器可正常加载浅色路线工作台。顶部导航、四步任务轨道、MapLibre 二维地图、导入面板和本地优先提示均可见。点击“导入与校验”会将工作画布从遗留的三维模式切回二维地图。

“工具库”可从顶部导航独立打开，呈现路线工作台、三维巡游及后续小工具的扩展入口；两个已可用工具均提供返回相应工作流的“打开工具”操作。

点击“输出与巡游”后，Cesium 初始化已越过加载器并在页面中报告“地形：Esri · 影像：Esri”；说明外部化的 Cesium 脚本、Assets、Workers 与 Viewer 初始化链路已开始工作。

## 仍需真实设备复测

沙盒浏览器的三维画布在无活动轨迹时保持深色底，并在等待观察时未能返回截图。该环境此前已有无头 WebGL 黑屏限制，不能据此判断真实桌面 GPU 的最终场景可见性。发布前应以 Chrome 或 Edge 导入一条真实 GPX 后进入“三维巡游”，确认地形、影像、路线实体与相机控制均可见。

## 构建与资源路径

生产构建已成功完成。Cesium 使用 `/cesium/Cesium.js` 延迟加载；开发服务器的 `/cesium/Assets/*`、`/cesium/Workers/*` 与 `/cesium/Widgets/*` 已验证通过 GET 请求返回相应的 JSON、JavaScript 与 CSS 内容类型。

2026-08-20 的最终构建再次通过，确认 `dist/public/cesium/Cesium.js` 和 `dist/public/cesium/Workers/` 均存在。桌面与 390px 宽手机视口均已检查：手机端采用自适应工作区高度，高程带位于完整操作抽屉之后，不会遮挡路线导入、轨迹列表或工程存档。
