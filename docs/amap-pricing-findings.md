# 高德地图 API：免费与商用初步核验

**核验日期：2026-08-19（GMT+8）**

高德开放平台的地图 JS API 2.0 概述页将其表述为“免费提供”的 Web 地图渲染引擎；官方基础服务计费页则说明，基础服务按账号权限和月配额计费，月配额超出后会依次消耗流量包与账户余额。旧版 JS API 概述页还明确指出，**非商业目的**可免费使用，而商业目的需要遵循商用授权路径。[1] [2] [3]

因此，对“能否免费获取”应作如下区分：

| 场景 | 初步答案 | TrailCraft 含义 |
| --- | --- | --- |
| 注册开发者账户、申请 Web JS API Key 与安全密钥 | 可以自行申请，官方文档将 JS API 2.0 描述为免费提供。 | 可用于原型、内部预览和技术验证。 |
| 基础服务月配额内的调用 | 受账号权限与当前配额规则约束；不应假定无限免费。 | 需在控制台确认当前 Key 的实际配额、域名限制和超额策略。 |
| 超过月配额 | 官方说明会消耗流量包或账户余额。 | 必须设置调用量监控与预算上限，避免上线后不可控成本。 |
| 商业性公开产品 | 不能仅根据“免费 Key”推定可无限制商用；官方商务合作页明确将商业目的列为需获取商用授权的场景。 | 在正式公开发布前，应与高德确认 TrailCraft 的产品形态、调用量、地图展示与导出分发是否纳入授权范围。 |

本项目当前已决定在地图合规结论前不主动对外发布。因此，高德的免费 Key 即使后续取得，也应首先用于**内部适配、真实设备测试和合规咨询准备**，而非自动触发对外上线。
